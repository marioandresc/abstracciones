# Índice Conceptual — Abstracciones

Este documento organiza los materiales Markdown del repositorio según su función dentro del proyecto. Distingue el **corpus primario** de las capas conceptuales, metodológicas y documentales construidas a partir de él.

> **Principio epistemológico:** el corpus primario constituye el registro de las conversaciones; las páginas conceptuales y metodológicas constituyen capas posteriores de análisis y organización. No deben tratarse como evidencia del mismo tipo.
