## Preparación para PDF

He dejado este compilado en formato Markdown listo para convertir a PDF. Opciones para generar el PDF:

1. Local (pandoc):

   pandoc Abstracciones_Memorias_Compilado.md -o Abstracciones_Memorias.pdf --pdf-engine=xelatex

2. En GitHub (Actions): crear un workflow que use pandoc or wkhtmltopdf para generar PDF desde Markdown y subir el artefacto / commit to repo.

3. Puedo crear ese workflow por vos: me autorizás y lo agrego en .github/workflows/generate_pdf.yml (se ejecutará y añadirá Abstracciones_Memorias.pdf al repo o como release).
